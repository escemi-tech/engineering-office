# engineering-office

Professional AI assistance and automation for software engineering, knowledge and business workflows.

Run a pinned Hermes gateway with persistent conversations and a local authenticated
API. Start with the [synthetic demo and runtime guide](docs/usage/hermes.md).
Cloud provisioning and private integrations remain pending.

Use the [Ansible deployment guide](docs/usage/hermes-deployment.md) to prepare
an approved Ubuntu host and install Hermes with scoped credentials.

Use the [shared writing policy](docs/usage/writing-policy.md) to review English
and French drafts. Hermes startup builds and loads this policy automatically.

Run `make help` for available commands. See the [documentation](docs/README.md)
for prerequisites, validation and deployment boundaries.
